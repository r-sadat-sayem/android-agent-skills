# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1.

In short: be respectful, assume good intent, and keep the focus on Android adaptive UI and AI skill development. Harassment, discrimination, or personal attacks have no place here.

If you experience or witness unacceptable behaviour, report it by opening a private issue or emailing the maintainer directly via GitHub.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
